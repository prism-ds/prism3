## (2026-11-24) — Motion phase 1: presets become a published alias tier, a clean break (#2857)

Built to the owner's structure: primitives → roles → `motion.preset.<name>.<slot>`, with patterns left for phase 2. The decisions it follows: the phase 1 batch (Q-MP2–Q-MP17, G3 B, G6 B), the spec-analysis revisits (Q-MP3 D, Q-MP25 A, Q-MP26 A), the structure review (Q-MS1–Q-MS10), the clean break of 2026-11-24, and the Figma checks (Q-MS10).

- **The preset tier.** Each preset is `motion.preset.<name>.{duration,easing,delay,duration-reduced}`, and every slot is an alias, never a number (Q-MS2 A). The defaults are the Q-MP8 rows, each slot on the role it used, so a role edit still reaches every preset a brand hasn't re-pointed. The reduced slot is derived from the duration (Q-MS6 A).
- **The composite is at `motion.preset.<name>.transition`, not `motion.preset.<name>` (an owner question).** DTCG has no node that is both a token and a group. The 2025.10 spec's answer, a group's `$root` token, isn't read by Style Dictionary 5.5, which the consumability gate runs, so the composite sits beside its slots.
- **The spring rule.** A preset eased by a spring plays for that spring's settle time. The engine fills the duration in when it's absent, and refuses any other duration by name, both ways. Its easing slot aliases the spring's CSS curve (`spring-easing`, a CSS-only type), and its composite is `springTransition`, a custom type the conforming projection omits. A `transition` composite there would leave a dangling alias in the projection, which has no rule for aliases to omitted leaves.
- **Reduced motion is `min(full, 100ms)` (Q-MP17 A).** This changes values, not names. The one name it moves is `motion.duration-ms.50`. The old rule floored every brand's reduced `normal` to 50ms, so the step was guaranteed; it's brand-dependent now. `motion.duration-ms.0` stays guaranteed, because a preset that starts at once aliases it.
- **The effects spring needed a technical change.** G1 A sets stiffness 1600, but `spring.ts` capped stiffness at 1000, where its `linear()` error bound was argued at 5ms sampling. A spring stiffer than that is now sampled at √(8 · (bound − rounding) / k): 4.7ms at 1600. The bound is unchanged, and every existing spring keeps its 5ms stops byte for byte. The test sweep now reaches k = 4000.
- **Delay: built as G6 B's option text (`show` 400ms, `min-show` 500ms).** The decision summary said "show and hide", and no hide value was ever proposed, so that goes to the owner.
- **Figma.** The preset slots are published TIMING and EASING aliases. Springs become hidden primitives, now that a preset is the handle on them. A spring's settle time is a hidden TIMING primitive a spring preset's duration aliases. The TIMING unit is seconds, as every existing TIMING variable is written; it's still unconfirmed (Q-MS10). **Distance has no Figma form yet** (#4589). A FLOAT aliasing `space/100` crosses collections, and both motion writers bind aliases only among the variables they write.
- **Brand curves (Q-MP3 D).** They sit beside the six, hidden in Figma. Guardrails: valid x, no overshoot, a name that isn't one of the six, and a shape that fits the role using it (enter decelerates, exit accelerates). The six are not held to the role rule, so `enter → calm` still works.
- **The clean break.** The four `motion.transition.*` are gone from the tree, the contract and every reader:
  - Studio's eased scroll reads `motion.preset.crossfade.transition`, the same step and role (#2041 kept it on one composite);
  - Studio's motion preview traces the presets;
  - the component defs name role pairs, behavior-identical, except Accordion, which takes `motion.preset.expand` as its recipe says.
- **What the gates found, each fixed or recorded:**
  - **The MCP paste path** ships the motion collection as one `figma_execute` script under a 45,000-character ceiling, and the presets pushed it over (48,696). It now ships as two scripts: `motion variables`, then `motion presets`. The second's aliases bind because the executor reads every variable already in the collection.
  - **TokenPress folds the preset slots into a broken composite (#4593).** Its grouping fires on any child name containing "duration", "delay" or "easing", and keeps the last match, so the reduced duration becomes the duration and the curve falls back to linear. TokenPress is a guest, so it isn't changed here. `exporter-comparison` and `readback-parity` exempt exactly this fold. Each holds it as a bijection over the presets Prism3 emits, so the exemption fails by name once the fold stops.
  - **A materialization deletion:** a snappy brand's `motion/duration-ms/50` lost its last alias under Q-MP17. It's recorded in `MATERIALIZATION_DELETIONS`, with the decision.
  - **CR-04's schema arm changed form.** A brand curve is a name the schema can't know, so the schema now refuses a malformed curve name and the engine an unknown one, by name.
