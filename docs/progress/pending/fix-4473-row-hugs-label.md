## (2026-11-24) — Checkbox.Row and Radio.Row hug their label (#4473)

A rebind rehearsal placed a `checkbox-row` on a sign-in screen and set its width to HUG; it stayed 320 wide. **Diagnosis:** since #1424 and Q152.3 the row's label FILLED the row and wrapped, which needs a bounded width, so the root was built FIXED at 320 (`placementWidth`) with a 120 floor. A HUG override on the instance then had nothing to hug: the label's width was the row's. `radio-row` had the same construction; `switch-row` already hugged (row, content and label), so it was the template, not a third fix.

**Fix (owner decision A, 2026-11-24):** the row, its `content` and `textStack` hug, and the label and description hug their text (no `wrap`). No executor change, so `EXECUTOR_REVISION` stays at 74 and `executor-reach.json` is untouched. A parent still stretches a row: Checkbox.Group and Radio.Group's `crossAxisFill` rows still span the group (Q155 block, unchanged and green), and a FILL instance reads the column's width.

**Tests.** `test-roundtrip.ts` places the default member of each of the three Rows in an auto-layout column with HUG width and holds it to the label's own run: 20 more label characters widen the instance by exactly 120px (the shim's 6px advance), and the member reads under 320. Before the fix it fails by name (`#4473 checkbox-row hugs its label when placed`, 320 → 320). The FILL arm reads 505 in a 505px column and 280 in a 280px one. The #1424 arms in `test.ts` and `test-roundtrip.ts` encoded the old fill-and-wrap shape, so they now assert the hug, each with a mutation that restores `wrap` and fails by name.

**Held for the owner:** in Figma a long row label no longer wraps. It ran on one line before only when unplaced at 320; now it runs on at any width, including a stretched row, until a designer sets the label to fill. In code it still wraps at its container's width. Keeping the hug *and* a Figma wrap point would mean extending `wrap: 'hug'` (today it needs a root built at a fixed width) to a hugging root with a stated max width, which is a new schema field and a choice of wrap width.
