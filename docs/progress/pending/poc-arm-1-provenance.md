## (2026-11-23) — Ejection, source mode: the copies carry a provenance line, not a generated header (#3408)

**What changed.** Owner decision 3 on #4471 (2026-11-23). In source mode, `tools/poc-ejection/copy-source.mjs` now
replaces each copy's "GENERATED by packages/…; do not edit; regenerate" header with one provenance line, which names
the package and version it was copied from. Everything after the header is still copied byte for byte. Files with no
generated header (`password-field.js`, the element package's `index.js`, `custom-elements.json`) are copied unchanged.
The provenance wording is a draft, held for the owner in the PR body. No engine change.

**The header is one line in the elements and two in the CSS.** The CSS header's "do not edit; change the def and
regenerate" is on its second line. Replacing only the first line would have left that stale instruction in the client's
own copy. So the copy script replaces through the line that ends the instruction.

**Source mode, measured:** count (a) fell from 13 to **5**, so the row still reads FAIL. Every remaining reference is
the same third header line of each CSS copy: "Markup contract: packages/css/README.md". The copy script leaves the
README out, so it points at a file the client doesn't have. The owner's decision covered the generated line only, so
this lane didn't touch it; it's filed as #4494. The upstream measurement now reads "the copied components by the
version their copies carry", because the provenance line names `@prism3/<package>@<version>`. That marks where a copy
came from. Nothing delivers a change to it yet (#3411).

**Checked:** a new `eject.ts --self-test` case runs the real copy script. Each copy whose source opens with a generated
header must open with `<package>@<version>`, and its header must name no repo path by the counter. The rest of the file
must be byte for byte its source. The case failed by name before the change. Three mutations each fail it by name: the
old header kept, the version dropped from the line, and one line too many cut.
