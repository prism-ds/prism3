Motion reaches Figma as animation styles (#2857, motion phase 3). Apply Theme writes one Figma animation style for each motion pattern, or for each element of a pattern that moves several (a dialog's scrim, panel and content), and a reduced sibling where the element still moves under reduced motion. Every pattern is a folder holding its default and reduced styles, such as "Dialog / enter / panel / default". Every entry is one of Figma's own animations (Opacity, Scale, Position, Rotation or Size) and binds the published preset variables the pattern names, such as `motion/preset/surface/duration` and `…/easing`, never a hidden primitive, so re-pointing a preset re-times every style that plays on it. An update keeps each style, so the layers that use it keep it too, and replaces its entries, because an entry cannot be edited once added. No Figma animation carries a fill color, so hover and press are style-guide rows only. TIMING variables are in seconds, as they have been since they were introduced, and a test now holds them to it. The style guide gains an animation table, with one row per style and its reduced sibling in the same row. A Figma without animation styles skips them and says so.
