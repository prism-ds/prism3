Motion phase 2 (#2857): the pattern file, exit halves, and two new presets. `CONTRACT_VERSION` takes a MINOR, 16.1.0: 38 names are added and none is removed or retyped.

- **Exit halves.** Each preset that brings something in (`fade`, `reveal`, `surface`, `settle`, `pop`) carries its closing half at `motion.preset.<name>.exit`, with the same five slots, one step shorter on the exit role. A brand re-points it like any other slot, under `motionPersonality.presets.<name>.exit`. An exit on a preset that plays in place is refused by name.
- **Two presets.** `motion.preset.pop` is a quick arrival, on the fast step with the enter role, for a tooltip, popover or menu. `motion.preset.press` is a press, on the instant step with the default role. `motion.preset.move` now defaults to the normal step, so the in-place travels it times (the tabs underline, the switch thumb, the segmented control's pill, the accordion's indicator) keep their timing.
- **Two delays.** `motion.delay.hide` is how long a tooltip stays after the pointer leaves. `motion.delay.skip` is the window in which the next tooltip shows at once. Both are 300ms, and neither scales with tempo.
- **The pattern file.** A motion pattern is one component half that moves, such as `dialog/enter`. It lists its tracks: each moves one element through one property group on a named preset, with its own distance or start scale and what it does under reduced motion. The starter set is 22 patterns. Each pattern must still show a cue under reduced motion, or it is refused by name. A brand changes a track's preset, distance, start scale or reduced kind under `motionPersonality.patterns`, never which tracks exist. A distance must name a token that exists, and a track never plays on the opposite half's preset: an entrance on an exit half, or an exit on an entering half. Each is refused by name.
- **Where the patterns go.** The agent file lists them in `motion_patterns` (schema 0.9). A component definition names the patterns it plays in `motion.patterns`, and its motion prose is generated from them, so the two can't disagree. The component export (1.8) and the component docs (1.3) carry the names.
