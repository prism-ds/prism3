A style guide, a build or Update file no longer stalls for up to an hour while Figma's window is hidden (#4476). Each run now hands control back to Figma only once about 50 ms of work has run, and it times each hand-back. A sustained run of late hand-backs (four in a row at least 250 ms late, or two of 5 s) means Figma has throttled the plugin's timers, which it does while its window is hidden: first to the next whole second, after about five minutes to the next whole minute. The run then does more work between hand-backs, up to 15 s, and goes back to 50 ms as soon as one comes back on time. In the tests, a run now takes about 1.1 times its working time while timers run once a second and about four times while they run once a minute, where it waited up to a second, then a minute, for every 50 ms of work or every table. The run's progress line also says why it is slow once this is detected. A warm rebuild also stops waiting on hundreds of hand-backs around almost no work (#724). Plugin only; no committed artifact changes.
